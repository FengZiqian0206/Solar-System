# Colour-cycling cursor / lattice roaming

- Overview and roaming are fixed at 50³ (125,000 grid points). The disabled density slider stays disabled after startup; old density events cannot rebuild the scene.
- Desktop mouse cursor: 16px flat colour-cycling dot, 70% opacity and a four-second colour cycle; “Double-click to start” fades on a five-second cycle after an initial five-second delay.
- Double-click enters fullscreen and hides names and leader lines. Spawn snaps to the existing grid vertex nearest Earth's current centre. Earth is sampled only on entry; subsequent orbital motion does not move the player.
- Hold W to move along the camera's viewing direction at 4.5 world units/second (50% faster than the previous version). Continuous travel drives a smooth third-person camera; the highlighted position is always snapped to an existing lattice vertex. Travel is clamped to the cube's ±26 bounds. Keyup, blur, hidden tab and exit clear movement.
- The selected point has a minimum size of 26 CSS pixels, with 70% opacity and a four-second colour cycle. The surrounding group's radius is 2.1 grid steps (19% smaller); its 95% colour-sharing core ends at 1.05 steps. Each cell ramps toward its target with a 0.22-second rise time constant and a slower 6-second fade time constant (about 0.5 seconds to 90% arrival, 14 seconds to fade by 90%). Slower fading extends the trail while travel speed stays unchanged. The influence centre follows continuous travel so upcoming cells begin colouring before the selected grid vertex changes. Base coordinates and the selected point stay on the grid; nearby points can render off-grid under repulsion.
- Influenced points retain an opacity floor of 55% times influence (about 52% for the closest settled neighbours); already-opaque points are not dimmed. Immediate core neighbours enlarge by up to 65%, tapering outward and capped at 64 CSS pixels; outer and trail point sizes stay unchanged. A temporary colour trail fades back to the normal appearance. There is no extra sphere, glow or deleted point. Re-entry clears all previous influence.
- Repulsion surrounds the colour core out to 5.5 grid steps. It ramps outward beyond 2.1 steps, reaches at most 1.8 steps of displacement, then tapers to zero at the boundary. Offsets ease toward their targets with a 0.18-second time constant and return with a 0.9-second time constant (about 2.1 seconds to recover 90%). The selected point is explicitly pinned in the shader. Repulsion follows continuous travel independently of the much longer colour trail. Overview ignores offsets immediately; re-entry clears them.
- Overview horizontal dragging is flipped relative to the previous version (positive yaw delta). Roaming mouse-look keeps its existing negative yaw delta. Vertical rotation is unchanged in both modes; browser tests verify each independently.
- Camera starts 32 units behind the player (previously about 12), mouse movement turns without dragging, wheel changes distance between 6 and 90, and Esc/Exit restores overview. Existing overview appearance, orbital data, charts and saved overview camera/follow state remain unchanged.
- Uses existing Three.js and native fullscreen/pointer lock; no additional runtime dependency. Pointer-lock refusal falls back to ordinary mouse movement. Fullscreen refusal leaves overview usable and displays retry guidance.
